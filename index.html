Aspectos Éticos e Legais da Comunicação em Sites

A comunicação em sites deve ser realizada de forma ética, respeitando os direitos dos usuários e garantindo informações verdadeiras e confiáveis. Além disso, é importante proteger a privacidade dos visitantes, utilizar imagens e textos com autorização e seguir as leis relacionadas aos direitos autorais e à proteção de dados pessoais.

Cumprir esses princípios aumenta a credibilidade do site e transmite mais confiança aos usuários.

Função e Importância da Gestão de Projetos

A gestão de projetos é o processo de planejar, organizar e acompanhar todas as etapas de um projeto para alcançar os objetivos definidos. Ela ajuda a controlar prazos, custos, recursos e riscos, tornando o trabalho mais eficiente.

Com uma boa gestão, é possível melhorar a qualidade dos resultados, reduzir problemas durante o desenvolvimento e aumentar as chances de sucesso do projeto.

Git e GitHub: Conceitos e aplicações.

O Git é um sistema de controle de versão. Ele serve para registrar e rastrear as alterações feitas em um projeto. Isso permite que você salve diferentes estados do seu trabalho, volte a versões anteriores quando cometer erros e colabore com outras pessoas.

As principais funções da ferramenta incluem:

  • Controle de versão seguro: Cada vez que você salva uma versão (um processo chamado de commit), o Git registra exatamente o que foi alterado. Se algo der errado, você pode restaurar o projeto para um estado anterior que funcionava perfeitamente.
  • Trabalho em equipe sem bagunça: Várias pessoas podem editar os mesmos arquivos simultaneamente. O Git junta essas alterações de forma inteligente e avisa se houver conflitos (quando duas pessoas alteram a mesma linha de um código).
  • Ramificações (Branches): Permite que você crie cópias independentes do seu projeto para testar novos recursos ou corrigir erros sem alterar o código principal (conhecido como main ou master).

Já o GitHub tem a função de hospedar códigos-fonte e facilitar a colaboração e o gerenciamento de projetos de software. Ele funciona como uma plataforma de armazenamento na nuvem integrada ao Git, que é a ferramenta que registra e controla todas as versões do seu código.

Por que ele é tão utilizado?

  • Trabalho em Equipe: Permite que vários programadores trabalhem no mesmo projeto simultaneamente sem alterar ou sobrescrever o trabalho uns dos outros.
  • Rastreamento de Histórico: Como usa o sistema Git, você nunca perde uma versão anterior. É possível saber exatamente quem alterou o código, o que foi mudado e quando.
  • Gerenciamento de Tarefas: Oferece ferramentas como Issues (para relatar bugs ou pedir melhorias) e Projects (para organizar etapas de trabalho).
  • Portfólio Profissional: É amplamente usado como vitrine para desenvolvedores. Você pode mostrar seus códigos, documentações e até hospedar sites estáticos gratuitamente pelo recurso GitHub Pages.

Docker: Finalidade e principais benefícios.

O Docker é uma plataforma de software desenvolvida para facilitar a criação, o envio e a execução de aplicativos por meio de containers.

O Docker utiliza a tecnologia de conteinerização. Em vez de criar uma máquina virtual inteira (que exige um sistema operacional pesado e consome muitos recursos), o contêiner compartilha o mesmo núcleo (kernel) do sistema operacional da máquina onde está instalado, isolando apenas a aplicação e o que ela precisa para rodar

Suas principais vantagens são:

  • Ambientes Padronizados: O contêiner criado no seu notebook funciona exatamente igual no servidor de produção, pois leva tudo o que precisa junto.
  • Leveza e Performance: Como não necessitam de um sistema operacional completo para cada aplicação, iniciam em segundos e utilizam muito menos memória e processamento que as máquinas virtuais tradicionais.
  • Agilidade no Desenvolvimento: Adicionar um novo banco de dados (como PostgreSQL ou Redis) leva apenas um comando, sem instalações complexas na máquina principal.
